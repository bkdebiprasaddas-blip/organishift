# Work Log — 2026-09-25

## What I set out to do
Add developer quick-login test user buttons below the login form on the Login
page, so a developer can click one of the seeded demo accounts to pre-fill the
email and password fields (instead of typing them every time).

## What I did
Edited `client/src/pages/Login.jsx` to add a "Developer quick-login" section
right below the existing Sign in button. The section has three buttons in a
**single row** — ADMIN, MANAGER, MEMBER — one per seeded role. Clicking any
button **pre-fills the email + password AND auto-submits** the login form
(no second click needed). Buttons show **only the role label, no email**.
A small caption line above the buttons shows the shared password
(`Password123!`) once.

Also diagnosed and resolved the "login is not working" report: the root cause
was the MongoDB database had **not been seeded** on the running server
instance — no demo users existed. Ran `node server/src/seed/seed.js` to
re-create the 4 seeded accounts. No auth-code fix was needed (bcrypt compare
in `authController.js:24` is correct).

## Decisions
- **Auto-submit, not pre-fill-only:** user reported login wasn't working;
  after seeding the DB, login works. Buttons now auto-submit so there's no
  second click — just tap ADMIN/MANAGER/MEMBER and you're in.
- **Single row, label-only:** per user request ("in single row", "dont show
  any email in button").
- **One button per role bucket:** member1 and member2 share the MEMBER role,
  so one MEMBER button covers both.
- **Only seeded LOCAL credentials** shown (not the `test.com` test-suite
  accounts, which don't exist in a normal local DB).
- **Styled** with the page's existing slate/indigo palette (flex-row, gap-2).
